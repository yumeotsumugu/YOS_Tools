# PDF Craft

ブラウザだけで動く、ローカル完結のPDF加工ツール。
PDFは外部サーバーへ送信されず、すべて端末内で処理されます。ビルド不要・インストール不要。

## 使い方

### かんたん（推奨）

このフォルダで簡易サーバーを立ててから開くと、すべての機能がフルスピードで動きます。

```sh
# 例: Python が入っている場合
python -m http.server 8000
```

ブラウザで <http://localhost:8000/> を開く。

### ファイルを直接開く

`index.html` をダブルクリックしても動作します。
※ `file://` で開いた場合、PDF.js のワーカーが使えずサムネイル生成がメインスレッド実行になり、大きなPDFで一時的に固まることがあります。実用上は問題ありません。
※ Firefox / Safari は `file://` の制限が厳しめのため、うまく表示されない場合は上記「かんたん（推奨）」の簡易サーバー経由で開いてください。

## 動作環境

- OS: Windows / macOS / Linux（ブラウザが動けばOK）
- ブラウザ: Google Chrome・Microsoft Edge（Chromium系）、Firefox、Safari の最新版
  - 必要API: ES2020、`crypto.getRandomValues`、Canvas、File API（2021年以降のブラウザならほぼ対応）
  - Mac は Cmd キー、Windows/Linux は Ctrl キーでショートカットが動作します

## ファイル構成

```text
index.html   画面（HTML + CSS）
app.js       アプリ本体
lib/
  pdf-lib.min.js       PDF生成・加工 (pdf-lib 1.17)
  pdf.min.js           PDF表示・サムネイル (PDF.js 3.11 UMD)
  pdf.worker.min.js    PDF.js ワーカー
  jszip.min.js         分割時のZIP出力 (JSZip 3.10)
```

すべてローカルに同梱。外部CDN・ネットワーク接続は不要です。

## 実装済みの機能（仕様書 Ver.1.0 準拠）

- PDF読み込み（ボタン／ドラッグ＆ドロップ／複数同時、大容量ファイル警告）
- ページサムネイル一覧・情報表示（元ファイル名／元ページ／回転角）
- ページ整理: 並べ替え（D&D）・削除・複製
- 回転: 選択／全／奇数／偶数ページ、左90°・右90°・180°・リセット
- 抽出: 選択ページを新規PDFへ
- 結合: 複数PDFを読み込み順番を整えて1つに
- 分割: 分割位置指定（例 `3,7`）／Nページごと／全ページ1枚ずつ → ZIP出力
- ページ番号入力での選択（例 `1,3,5-10,15`）
- Undo / Redo / リセット
- 保存（元PDFは変更せず新規ファイルとして書き出し）
- ショートカット: Ctrl+S 保存 / Ctrl+Z 元に戻す / Ctrl+Shift+Z やり直す / Ctrl+A 全選択 / Delete 削除
