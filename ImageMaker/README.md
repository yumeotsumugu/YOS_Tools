# ImageMaker

ココフォリアで使うルーム素材・TRPG素材を、専門的な画像編集ソフトなしでブラウザ上で作れるWebアプリです。

## 使い方

`index.html` をブラウザで開くだけで動作します（インストール不要・サーバー不要）。
画像はすべてブラウザ内で処理され、外部へ送信されません。

（実装メモ）ES Modules(import/export)はfile://で直接開いた際にCORSでブロックされるブラウザがあるため、
素の `<script>` タグ読み込み＋ `window.IM` 名前空間方式で実装しています。

## 修正・追加（フィードバック対応）

- [x] 枠線が反映されない不具合を修正（線の色の初期値が完全に透明だったため、太さを設定しても見えなかった）
- [x] 図形（四角形・円）にグラデーション塗りを追加（2色・角度指定、プロパティパネルの「グラデーションにする」で切替）
- [x] テキストの縦の揃え（上／中央／下）を追加
- [x] 複数選択（Shift+クリック、キャンバス上・レイヤーパネル両方対応）
- [x] 複数選択時のまとめ移動・複製・削除・コピー＆貼り付け
- [x] 「配置」パネル：重ね順（前面へ／背面へ／最前面へ／最背面へ）、整列（上下左右・中央、1件選択時はキャンバス基準／複数選択時は選択範囲基準）、均等配置（垂直に／水平に、3件以上必要）、整列する（1列に整列、2件以上必要）
- [x] APNG（アニメーションPNG）生成機能を追加（ヘッダーの「🎞 APNG」ボタン）
  - 選択オブジェクトを動かす：点滅・フェード・明滅・上下移動・左右移動・拡大縮小・回転・揺れの8プリセットで、選択中のオブジェクトをアニメーションさせたAPNGを生成（速度・強さ・長さ・ループ回数を指定可、プレビュー確認可）
  - 複数画像から作る：画像を追加してドラッグ＆ドロップで順序変更、フレーム間隔とループ回数を指定してAPNGを生成
  - APNGはブラウザ標準APIでは生成できないため、CanvasのPNG出力を独自にAPNGチャンク(acTL/fcTL/fdAT)へ組み立て直す自前エンコーダを実装(外部ライブラリ不使用)。node-canvas・Pillowによる独立検証済み
- [x] PNG書き出し・APNG生成それぞれにファイル名入力欄を追加（禁止文字は自動的に置換、空欄時は既定のファイル名を使用）
- [x] プロジェクト管理を追加
  - スタート画面に「プロジェクト名」入力・「プロジェクトを開く」（JSONファイル読込）・「最近のプロジェクト」一覧を追加
  - 編集画面ヘッダーの「💾 保存」でプロジェクトをJSONファイルとしてダウンロード（画像はBase64で埋め込み、JSON単体で復元可能）
  - IndexedDBへの自動保存に対応（編集のたびに自動保存され、フッターに保存時刻を表示）
- [x] レイヤー結合を追加(「配置」パネルの「🔗 レイヤーを結合」、2件以上選択で有効)。選択範囲全体を1枚の画像として合成し、元のオブジェクト群と置き換える
  - 結合前の元オブジェクトは合成後の画像側に保持され、「🔓 結合を解除」でいつでも元に戻せる(プロジェクトをJSON保存・再読込した後でも解除可能)
- [x] テキストのフォント選択に対応
  - 定番フォントを標準搭載(OS標準のゴシック/明朝/等幅 + Google FontsのNoto Sans JP、Noto Serif JP等 計13種)
  - 「＋ フォントを追加」から.ttf/.otf/.woff/.woff2ファイルを追加すると、その場で使えるようになり、ブラウザ内(IndexedDB)に保存されて次回以降も自動的に使える(フォルダを毎回指定する必要はない)
- [x] 図形パターンを大幅に追加（左パネルの「▦ 図形を選ぶ」から17種類を選択可能）
  - 矢印（回転機能で4方向すべてに対応）、折線矢印、Uターン矢印
  - 吹き出し（四角／角丸／丸、しっぽの位置・大きさを調整可能）
  - 星（頂点数・とがり具合を調整可能）、正多角形（角の数を調整可能）
  - 線・線矢印（破線・両端矢印に対応）、付箋（右下折/左下折）
  - 直角三角形、台形、部分円、ハート、雲形、十字
  - 図形全般に左右反転・上下反転を追加
  - 図形一覧は四角形/円の直下に常時表示（開閉不要）
- [x] 吹き出し(丸)のしっぽが楕円の輪郭からずれる不具合を修正、雲形をより雲らしい輪郭に改善
- [x] テーブル(表)機能を追加（左パネルの「⊞ テーブル」）。行数・列数、見出し行の有無、罫線・配色、フォントを調整でき、各セルの内容はプロパティパネルから編集可能。TRPGのランダム表やステータス表作成を想定
- [x] テキストボックスの自動改行(ボックスの幅に合わせて折り返す)に対応。デフォルトON、「ボックス内で自動改行する」チェックボックスでOFFにすると従来通りの挙動に戻せる
- [x] テーブル機能を拡張：背景の透過表示、セルごとの個別背景色・文字色・文字揃え(左/中央/右)に対応(ミニグリッドでセルを選んで編集)
- [x] 画面レイアウトを変更：「レイヤー」パネルを右側から左側(追加とキャンバスの間)へ移動し、開閉可能に(「◀/▶」ボタン)。右側は「プロパティ」のみに
- [x] レイヤーパネルの幅をドラッグで調整可能に。調整した幅はブラウザに記憶され、次回開いたときも同じ幅で表示される
- [x] 編集画面ヘッダーに「🏠 ホームへ戻る」ボタンを追加(確認ダイアログ付き)。スタート画面・編集画面どちらからも開ける「❓ 使い方」ガイドを追加
- [x] フリーハンド描画(ペンツール)を追加。左パネルの「✏️ ペン」でON/OFFし、太さ・色・破線を指定してドラッグで自由に描ける。描いた線は他の図形と同様に選択・移動・拡縮・回転・色変更が可能
- [x] macOS対応：キーボードショートカットはCtrl/⌘どちらでも動作(既存)。macOSで開いた場合、ヘッダーボタンやフッターの案内、使い方ガイドの表記が自動的に「⌘」表示に切り替わる
- [x] 図形・画像の「塗りの不透明度」「線の不透明度」を独立して調整可能に(全図形共通)

- [x] 四角形以外の図形にも角丸対応（直角三角形・台形・正多角形・星・十字・付箋・矢印）。頂点の並びから角を自動的に丸める汎用処理で、星や十字の凹んだ角にも丸みが付く

## ディレクトリ構成

```
ImageMaker/
├─ index.html
├─ css/
│  └─ style.css
├─ js/
│  ├─ app.js        … アプリのエントリーポイント（画面制御・結線）
│  ├─ canvas.js      … Canvas描画・選択/移動/拡縮/回転
│  ├─ layers.js       … レイヤーパネル
│  ├─ objects.js      … オブジェクトのデータモデル・当たり判定・図形定義(SHAPE_KIND_DEFS)
│  ├─ shapes.js       … 拡張図形(矢印/吹き出し/星/多角形など)の描画ロジック
│  ├─ export.js      … PNG書き出し(APNGフレーム描画の共通処理も担う)
│  ├─ apng.js         … APNGエンコーダ・アニメーションプリセット計算
│  ├─ project.js       … JSON保存/読込・IndexedDB自動保存
│  ├─ fonts.js         … フォント管理(定番フォント一覧・カスタムフォントの追加とIndexedDB永続化)
│  ├─ utils.js        … 汎用ヘルパー
│  ├─ history.js      … Undo/Redo履歴管理
│  ├─ templates.js      … (Phase 4 プレースホルダー)
└─ assets/
   ├─ icons/
   └─ templates/
```
